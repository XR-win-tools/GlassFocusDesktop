# Glass Focus

一个 Windows 桌面悬浮小工具，深色实底 + 玻璃质感卡片，包含时钟、番茄钟、待办清单。

## ✨ 功能

- 实时时钟
- 番茄工作法计时（25 分钟工作 / 5 分钟休息，自动切换并响铃）
- 今日待办清单（添加、勾选完成、删除）
- 窗口置顶、折叠、拖动
- Win11 系统圆角 + 深色玻璃卡片视觉

## 🚀 直接运行（推荐）

从 [Releases](https://github.com/你的用户名/GlassFocusDesktop/releases) 下载最新的 `GlassFocusDesktop.exe`，双击即可运行，**不需要安装 .NET 运行时**。
